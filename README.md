# 💌 Message for Senior

เว็บเล็กๆ ไว้ส่งข้อความถึงรุ่นพี่ เขียนด้วย HTML / CSS / JavaScript ล้วน ไม่ต้องติดตั้งอะไร เปิด `index.html` ในเบราว์เซอร์ได้เลย

## ✨ ลูกเล่น

- **ซองจดหมาย** แตะแล้วซองจะเปิด จดหมายเลื่อนขึ้นมา
- **หัวใจลอย** เป็นพื้นหลัง และแตะตรงไหนก็มีประกายเด้งออกมา
- **ข้อความพิมพ์ทีละตัว** แตะที่ข้อความเพื่อข้ามได้ และมีจุดบอกว่าอ่านถึงหน้าไหนแล้ว
- **คำถามตอนจบ** ปุ่ม "ไม่" จะหนีไปเรื่อยๆ ส่วนปุ่ม "ได้สิ" จะใหญ่ขึ้นทุกครั้ง 😝
- **พลุหัวใจ** ตอนกด "ได้สิ" (ใช้ [canvas-confetti](https://github.com/catdad/canvas-confetti))
- **เสียงน่ารักๆ** กดปุ่ม 🔇 ที่มุมขวาบนเพื่อเปิด
- **Easter Egg** 🐣 กดที่หัวข้อติดกัน 5 ครั้ง

## ✏️ แก้ไขยังไง

| อยากแก้ | ไปที่ |
| --- | --- |
| ชื่อ, ข้อความ, คำถาม, ข้อความลับ | `CONFIG` ด้านบนของ `script.js` |
| สีหลัก / ฟอนต์ | `:root` ด้านบนของ `style.css` |
| รูปรุ่นพี่ / รูปพื้นหลัง | `assets/Narak.png` / `assets/PPP.png` |
| หัวข้อหน้าแรก | `index.html` |

## 📁 โครงสร้าง

```
index.html   หน้าเว็บ
style.css    หน้าตา / animation
script.js    ลูกเล่นทั้งหมด
assets/      รูปภาพ
```
